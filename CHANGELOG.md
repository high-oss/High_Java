# Changelog

All notable changes to this project are documented in this file.

## 0.0.1

Initial release.

- `HighClient`, built via `HighClientOptions.builder()`, covering 24 of the
  spec's 27 operations across five resources: `auth()`, `orders()`,
  `portfolio()`, `scrips()`, `market()`. The redirect consent flow and token
  introspection are deliberately not wrapped.
- Every operation has a synchronous form and a `...Async` form
  (`CompletableFuture<T>`); cancelling the future reaches an in-flight
  request or a pending retry delay alike.
- Retries for idempotent reads only (429, 500, 502, 503, 504), honouring
  `Retry-After` in both its forms with a ceiling above which the SDK gives
  up rather than blocking.
- One error type, `HighApiError`, carrying `status`, `code`, `requestId`,
  `messages` and `body`; `code` is an open string backed by the
  `ErrorCodes` catalogue.
- Structured, redacting logging (`LogLevel.SILENT` by default) with
  credential-safe URL and body redaction.
- Models generated by OpenAPI Generator from the spec pinned in
  `spec.lock.json`, with two schemas hand-written instead (see
  `scripts/regenerate.sh`).
